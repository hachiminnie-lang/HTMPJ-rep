## 新しく追加するとき

1. `施設名.md` を作る（例：`wako-ofuro-no-ousama.md`）。
2. チラシや時刻表の写真は `images/` に入れる。
3. 上の一覧表に1行足す。

各ページに書いておくと便利なこと：

- ハツの攻略メモ（行き帰りの方法、持ち物、安く済ませるコツ、有料オプションが要るかどうか）
- 住所・電話・営業時間・定休日
- 料金（平日／休日）
- 送迎バスの時刻表と乗り場
- 注意事項（持ち込み、タトゥー、お酒など）
